# Learning science behind Study Coach

Each note states one principle, the evidence behind it, and what the app does about it.
Effect sizes are summarised in `docs/ARCHITECTURE.md` (learning-science rules); follow
the links for the studies themselves. Nothing here is a claim that the app has been shown
to raise grades: it logs every answer so that can be tested (see the last note).

| Note | In one line |
|---|---|
| [Self-testing and spacing](self-testing-and-spacing.md) | Answer first, come back later: the two techniques with the best evidence |
| [Rereading is not study](rereading.md) | The Library is for reference and never counts as progress |
| [No learning styles](no-learning-styles.md) | Preferences change what is suggested, never a label |
| [Confidence and calibration](confidence.md) | Students misjudge what they know; confident mistakes come first |
| [Guessing first](guessing-first.md) | A guess before the answer helps, when feedback follows |
| [Teaching it back](teach-back.md) | Explaining as if to teach exposes the gaps |
| [Fading hints](hint-fading.md) | Support helps beginners and gets in the way later |
| [Sleep and distraction](sleep-and-focus.md) | Short nights and phones cost more than they feel like |
| [Interleaving](interleaving.md) | Mixing units helps tell similar ideas apart |
| [Practise in the exam's format](exam-format.md) | Mock exams match the real assessment |
| [What adaptive systems can claim](adaptive-systems.md) | Modest gains; measure rather than promise |
