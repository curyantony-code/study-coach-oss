# Interleaving

## The principle

Mixing related topics during practice helps students tell similar ideas apart, compared with finishing one topic before starting the next.

## What Study Coach does

- Assessment and whole-course sessions take new cards from each unit in turn.
- Studying one note can pull in the notes it links to (“with linked notes”).
- Mock exams are shuffled across units.
